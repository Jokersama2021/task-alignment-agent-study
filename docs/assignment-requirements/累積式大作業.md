# 累積式大作業（AT3）設計

## 總覽

| 作業  | 權重 | 內容 | → AT4 對應 |
|------|:--:|------|------|
| ① 文獻綜述 |  8% | 選定前沿方向，3-5 篇核心論文結構化調研 | Related Work |
| ② 技術復現 | 12% | 復現作業①中 1 篇論文方法，產出 code + 結果 | Method |
| ③ Agent 工作任務 | 10% | 用 Agent 完成一項工作 + 一個小型受控比較 | Experiments |

## ①：文獻綜述（8%）

### 要求
- 從教師提供的選題池中選擇一個前沿方向
- 閱讀 ≥5 篇論文（含 2 篇 2024+ 頂會論文）
- 產出：結構化知識圖譜（腦圖/表格） + 1 頁摘要

### 評分維度
| 維度 | 權重 |
|------|:--:|
| 選題前沿性 | 20% |
| 文獻覆蓋度（是否抓到關鍵論文） | 30% |
| 結構化組織（邏輯清晰、分類合理） | 30% |
| 批判性分析（不只總結，有自己的判斷） | 20% |

### 選題池（教師提供，示例）
- AI for Medical Imaging（醫學影像 AI 前沿）
- Medical LLM / Clinical NLP（臨床大語言模型）
- Surgical AI（手術影片理解與工具分割）
- Vision Transformer 及其變體
- YOLO 系列目標檢測演進
- Segment Anything 及視覺基礎模型
- LLM 對齊方法（RLHF/DPO/ORPO）
- 多模態大模型（VLM）架構比較
- AI Agents 框架與應用
- Diffusion Models 在圖像生成的應用
- SSM/Mamba 架構及其在 CV 的應用

## ②：技術復現（12%）

### 要求
- 從①的文獻中選 1 篇
- 復現其核心方法（可使用簡化版：小型數據集、少 epoch）
- 產出：可運行代碼（GitHub） + 結果截圖 + 簡要說明

### 評分維度
| 維度 | 權重 |
|------|:--:|
| 代碼可運行性 | 30% |
| 結果復現度（與原論文對比） | 30% |
| 代碼規範（註釋、結構、README） | 20% |
| 復現過程文檔 | 20% |

---

## ③：用 Agent 完成一項工作（10%）

### 任務

使用 Agent 或教師認可的 Agent 工具，完成一項離線來源整理工作：搜尋指定來源包、讀取三個相關來源、生成一頁含 citation 的研究簡報，並通過 final-state validator。

核心 fixture 免 API、模型、GPU、網路與大型套件。使用付費模型或 Agent framework 不會獲得額外分數。

### 一個小型受控比較

只選一項：

- `max_steps=3` 與 `max_steps=6`；
- 含糊與清晰 tool description；
- 單次 prompt 與 Agent tool loop。

比較時保持任務、來源包、validator 與 rubric 不變。

### 提交

- 一頁 `final-brief.md`。
- `task-contract.json`、`tool-schema.json`、`trajectory.jsonl`、`tool-results.jsonl`、`evaluation.csv`、`error-note.md`、`provenance.json`。
- 兩頁以內分析：完成狀態、tool calls、最容易出錯的步驟、小比較結果、限制與下一測試。

### 評分維度

| 維度 | 權重 |
|---|---:|
| 工作完成與 final-state validator | 30% |
| tool calls、observations 與 citation evidence | 25% |
| 小比較與失敗分析 | 25% |
| provenance、可重跑性、安全邊界與表達 | 20% |

只交截圖、缺少 trajectory，或把教師 fixture 宣稱為真模型輸出，均不視為完整提交。

## 注意事項

- 三部分彼此關聯
- 共 30%
- 作業遲交：每天 -10%，逾 7 天 0 分
