# AT4 期末整合報告 — 完整指南

## 形式

**雙軌提交：微型學術論文（PDF）+ GitHub Repository**

## 論文結構（8-10 頁）

| 章節 | 來源 | 頁數 |
|------|------|:--:|
| Abstract | 新寫 | 0.5 |
| Introduction | 新寫 | 1 |
| Related Work | -- | 1.5-2 |
| Method | —- | 1.5-2 |
| Experiments | -- | 2-3 |
| Discussion | 新寫 | 1 |
| Conclusion | 新寫 | 0.5 |
| References | ≥10 篇 | — |

## GitHub Repo 要求

```
repo/
├── README.md          # 項目說明 + 環境配置 + 運行步驟
├── requirements.txt   # 或 environment.yml
├── src/               # 代碼
├── results/           # 實驗結果（圖表）
└── paper.pdf          # 論文 PDF
```

## 評分（40%）

| 維度 | 權重 |
|------|:--:|
| 研究課題意義與前沿性 | 15% |
| 文獻綜述完整性與批判性 | 20% |
| 技術復現正確性與可復現性 | 20% |
| 實驗設計嚴謹性與分析深度 | 20% |
| 論文寫作與學術規範 | 10% |
| GitHub Repo 質量與文檔 | 10% |
| 課堂展示與答辯 | 5% |

## 時間線

```

W13: 開始整合 → 補寫 Introduction/Discussion
W14: 完稿 + Repo 整理
W15: 提交 + 課堂展示（10min 報告 + 5min Q&A）
```
